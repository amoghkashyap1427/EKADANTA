# EKADANTA — The Story of Ganesha

## Short Description
A story-driven action-adventure game depicting the origin of Ganesha. Stand your ground, fulfill your mother's command, and witness the tragic but beautiful tale of how the elephant-headed deity was born.

## Genre
Story-driven Action-Adventure

## Objective
Guard the temple entrance at all costs. Stand your ground against any who would pass, and never break the promise you gave to your mother.

## Controls
- **WASD / Arrow Keys**: Move
- **SPACE**: Divine Strike
- **SHIFT**: Dash / Dodge
- **E**: Interact / Proceed Dialogue
- **ESC**: Pause / Menu

## Technology Used
- **Engine**: Python 3 / Pygame Community Edition (pygame-ce)
- **Web Deployment**: Pygbag (WebAssembly)
- **Hosting**: GitHub Pages

## How to run locally
Ensure you have Python 3.11+ installed.

1. Install dependencies:
```bash
pip install -r requirements.txt
```
2. Run the game:
```bash
python main.py
```

## Web Version Deployment
The web version is built using `pygbag` and deployed automatically to GitHub Pages via a GitHub Actions workflow on every push to the `main` branch. 
You can play the web build directly via the GitHub Pages URL associated with this repository.

## GitHub Repository
This repository contains the complete source code, assets, and GitHub Actions workflows for continuous deployment to GitHub Pages.
